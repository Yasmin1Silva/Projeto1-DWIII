# Projeto 1

## 📚 Sobre o projeto

Este projeto foi desenvolvido como uma atividade acadêmica com o objetivo de criar um site utilizando tecnologias de desenvolvimento web.

O projeto apresenta uma página inicial e páginas individuais com informações sobre os integrantes, além de seus respectivos currículos em formato PDF.


## ⚙️ Funcionalidades

- Página inicial do projeto;
- Página de apresentação dos integrantes;
- Página com informações sobre cada integrante;
- Acesso aos currículos em PDF;
- Navegação entre as páginas;
- Página de erro 404 para endereços que não existem;
- Servidor local utilizando Node.js.

  
## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
